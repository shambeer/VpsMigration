# Покрытие гайда Self-Steal и видео

Сверка: 28.11.2026. Основа — сохранённая версия [текстового гайда](https://denpiligrim.ru/guides/self-steal), его шаблоны и главы [видео](https://www.youtube.com/watch?v=cFOou-7pO24). Полная аудиодорожка/субтитры и буквальное повторение всех действий видео не подтверждены. Повторное открытие сайта через web-инструмент вернуло ошибку, поэтому актуальность всех изменений страницы после сохранённой версии не подтверждена.

## Точный счёт способов подключения

Считаются семь разных вариантов, без добавления Amnezia и старых резервных VPN к знаменателю:

| Вариант | Реализация | Живая проверка |
| --- | --- | --- |
| VLESS TLS / Vision | Есть | HTTPS прошёл для обеих ролей |
| VLESS TLS / XHTTP | Есть | HTTPS прошёл для обеих ролей |
| VLESS TLS через WARP | Есть | HTTPS и warp=on прошли для обеих ролей |
| VLESS REALITY / Vision на собственный сайт | Есть | HTTPS прошёл для обеих ролей |
| VLESS REALITY / XHTTP | Есть | HTTPS прошёл для обеих ролей |
| VLESS REALITY через WARP | Есть | HTTPS и warp=on прошли для обеих ролей |
| Hysteria2 | Есть | HTTPS прошёл для обеих ролей |

Итого: код для 7 из 7 вариантов; реальный работающий путь подтверждён для 7 из 7 в серверных контейнерных клиентах. Это покрытие вариантов подключения, а не процент покрытия всего сайта или видео и не проверка на телефоне.

## Остальные возможности

| Блок | Фактическое покрытие |
| --- | --- |
| Собственный сайт, Nginx, fallback / PROXY protocol | Реализовано, основной путь с сайтом испытан |
| Сертификаты, webroot, HTTPS | Реализовано; выпуск и reconfigure проверены. Продление после истечения срока не репетировалось |
| Расширенные параметры XHTTP / XMUX | Реализованы настройки и локальные проверки; все возможные комбинации отдельно не испытаны |
| Пользовательский статический сайт, дополнительные SAN-домены | Реализованы параметры и локальная валидация; не все варианты проверены живым ACME |
| HTTPS-подписки и страница доступа | Реализованы и проверены; Sub-Store — дополнение по запросу пользователя |
| Routing-профили Happ/INCY и дополнительный whitelist | Экспорт/настройки реализованы; импорт и работа на настоящем телефоне не подтверждены |
| Российский relay и ограничение входа к основному VPS | Реализовано; сквозная схема на двух VPS не испытана |
| Готовые 3x-ui и 3DP | Запуск, вход/API проверены. Автосоздание узлов/инбаундов и управление standalone-профилями через 3DP не сделаны |
| Общий TCP443 как в примере гайда | Намеренно изменено по решению пользователя: Amnezia приоритетна, новые способы на отдельных портах |

Прежняя формулировка FR-17 «функциональный набор гайда реализован» означает наличие перечисленных механизмов в коде. Её нельзя понимать как полную автоматизацию панели, готовый двухсерверный E2E или подтверждение всех пунктов видео.

Общий достоверный процент всего видео/сайта не установлен: согласованного исчерпывающего списка действий видео нет. Старые AmneziaWG/WG/OpenVPN/Shadowsocks/Telegram и служебные возможности мигратора не используются для искусственного увеличения покрытия этого гайда.
